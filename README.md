# ⚔️ MATH QUEST — Édition Titou (4ème)

Jeu de révision ludique pour le programme de **Mathématiques 4ème**, conçu dans l'univers **Minecraft, Pokémon, Berserk & One Punch Man** avec une ergonomie adaptée au TDAH.

## 🌐 Jouer / Installer sur Mobile
👉 **[Lancer MATH QUEST](https://vincenzorpg.github.io/Titou/)**

- **Android (Chrome)** : ouvre le lien puis clique sur **« 📲 Installer »** (ou menu `⋮` → *Installer l'application*).
- **iPhone / iPad (Safari)** : ouvre le lien → bouton **Partager** → **Sur l'écran d'accueil**.
- **PC** : ouvre le lien dans Chrome/Edge ou clique sur **📲 Installer**.

## ☁️ Synchroniser la progression (PC ↔ Mobile)
Clique sur **☁️ Sync** dans la barre supérieure pour :
1. **Partager / copier le Lien Magique** (ou le **Code Héros**) et fusionner la progression en 1 clic sans jamais perdre d'XP ou de trophées.
2. *(Optionnel)* Connecter une base gratuite **Firebase Realtime Database** pour une synchronisation automatique en temps réel.
